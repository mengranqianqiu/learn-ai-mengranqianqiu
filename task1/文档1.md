## 1.1 列表

1. 列表创建

    ```python
    a = [1, 2, 3, 4, 5]
    b = []
    c = [1, "hello", 3.14, [1, 2]]
    ```

2. 常用操作方法

    ```python
    a.append(6)
    # 在列表后面新加元素 6
    a.insert(2, 3)
    # 在下标 2 处插入 3，原元素后移，长度 +1
    a.remove(3)
    # 删除列表中的第一个 3
    a.pop()
    # 删除并返回最后一个元素；a.pop(n) 删除并返回 a[n]
    a.clear()
    # 删除所有元素，列表变成空列表
    a.index(3)
    # 查找 3 的索引位置
    a.count(1)
    # 计算列表中 1 出现的次数
    a.sort()
    # 升序排序列表；a.sort(reverse=True) 降序
    a.reverse()
    # 反转列表
     ```

3. 常用内置函数

    ```python
    len(a)
    # 求长度
    sum(a)
    # 求和
    max(a)
    # 最大值
    min(a)
    # 最小值
    b = sorted(a)
    # 返回新的升序列表
    ```

## 2.1 Lambda 匿名函数

1. 基本语法

    ```python
    f = lambda x, y: x + y
    f(1, 2)
    # 3
    ```

2. 常见用法

    ```python
    a = [3, 1, 4, 1, 5]
    sorted(a, key=lambda x: -x)
    # [5, 4, 3, 1, 1]        降序
    list(map(lambda x: x * 2, a))
    # [6, 2, 8, 2, 10]       每个元素乘 2
    list(filter(lambda x: x > 2, a))
    # [3, 4, 5]              保留大于 2 的元素
    max(a, key=lambda x: abs(x))
    # 5                      按绝对值取最大
    ```

3. 总结

     对比def

    ```python
    # lambda 写法
    f = lambda x: x + 1
    # def 写法，等价
    def f(x):
        return x + 1
    # lambda 函数无函数名，函数体只有单个表达式，且只能用一次，可读性差。
    ```

## 2.2 Decorator 装饰器

1. 概念

    - 装饰器是“用一个函数装饰另外一个函数并为其提供额外的能力”的语法现象
    - 装饰器本身是一个函数，它的参数是被装饰的函数，它的返回值是一个带有装饰功能的函数

2. 装饰器的基本结构

    ```python
    def record_time(func):
        def wrapper(*args, **kwargs):
            result = func(*args, **kwargs)
            return result
        return wrapper
    # func：被装饰的函数
    # wrapper：带装饰功能的函数，会替代原函数
    # *args, **kwargs：照单全收原函数的参数，再原封不动传给 func
    # return wrapper：返回新函数，替代原函数
    ```

    计时装饰器

    ```python
    import time
    def record_time(func):
        def wrapper(*args, **kwargs):
            # 执行前记录开始时间
            start = time.time()
            # 执行被装饰的函数并获取返回值
            result = func(*args, **kwargs)
            # 执行后记录结束时间
            end = time.time()
            # 计算并显示执行时间
            print(f'{func.__name__}执行时间: {end - start:.2f}秒')
            # 返回被装饰函数的返回值
            return result
        return wrapper
    ```

3. 调用方式

    - 直接调用

    ```python
    download = record_time(download)
    upload = record_time(upload)
    ```

    - 语法糖 @

    ```python
    @record_time
    def download(filename):
        print(f'开始下载{filename}.')
        time.sleep(random.random() * 6)
        print(f'{filename}下载完成.')
    # 语法糖在使用的时候，自动调用 download = record_time(download)
    @record_time
    def upload(filename):
        print(f'开始上传{filename}.')
        time.sleep(random.random() * 8)
        print(f'{filename}上传完成.')
    # 语法糖在使用的时候，自动调用 upload = record_time(upload)
    ```

4. 取消装饰器

    ```python
    from functools import wraps
    def record_time(func):
        @wraps(func)
        def wrapper(*args, **kwargs):
            start = time.time()
            result = func(*args, **kwargs)
            end = time.time()
            print(f'{func.__name__}执行时间: {end - start:.2f}秒')
            return result
        return wrapper
    # download.__wrapped__('MySQL必知必会.pdf')
    # upload.__wrapped__('Python从新手到大师.pdf') 可直接调用原函数
    ```

## 6.1 generator 生成器（yield 关键字）

1. 基本概念

    - 生成器是按需产出元素的函数，用 yield 关键字定义。
    - 每次 next() 才执行到下一个 yield，产出一个值后暂停。

    ```python
    def count_up(n):
        i = 0
        while i < n:
            yield i
            i += 1
    ```

2. yield 与 return 的区别

    ```python
    def f():
        return 1
        return 2
    # 第一个 return 就结束，2 永远执行不到
    def g():
        yield 1
        yield 2
    # 每次 yield 暂停，下次继续，两个都能产出
    ```

3. 基础用法

    ```python
    g = count_up(3)
    next(g)
    # 0
    next(g)
    # 1
    next(g)
    # 2
    next(g)
    # StopIteration
    ```
